## 为什么写博客

一直想要一个属于自己的角落，记录学习过程中的收获、踩过的坑，以及一些零碎的思考。这个博客就是为此而建。

## 技术栈

这个博客使用了以下技术：

- **Next.js 16**：React 全栈框架，支持静态生成
- **MDX**：在 Markdown 中直接使用 React 组件
- **Tailwind CSS v4**：原子化 CSS，配合 typography 插件排版文章
- **Vercel**：一键部署，全球 CDN 加速

## 写作计划

1. 每周至少更新一篇技术笔记
2. 每月一篇复盘总结
3. 不定期分享读书与生活

希望这个小小的站点能慢慢积累出有价值的内容。
